# 跨境 AI 工作台 · Ecom Workbench v1.6.20

一个**免安装**的亚马逊运营 AI 工作台。解压后双击 `Start.bat`（或 `启动.bat`），浏览器自动打开；填入自己的 DeepSeek API Key 就能用。

内置 15 个可用技能，覆盖选品、Listing、关键词、广告、竞品、差评、利润、库存、合规和客服。技能会读 Excel/PDF、联网查资料、用代码算账，并把 Listing、报告和测算表写成文件。还可以连接领星、卖家精灵、SIF、Sorftime 的 MCP 数据源。

## 用域名访问（不下载、不解压）

工作台本身是一个本地 Node 服务，不能直接放 GitHub Pages/静态空间。要让同事打开域名就能用，需要一台服务器 + 域名 + Caddy 反代 + 登录密码，步骤见 **[deploy/README.md](deploy/README.md)**。

> 当前是**单用户**工具：同一个域名/登录后面，所有人共享对话、workspace 和 MCP Key。只适合你自己从公司/家里访问；多人各自隔离要一人一实例或改造成多用户。

## 30 秒开始

1. 把压缩包**解压到桌面**（不要在压缩包里直接双击）。
2. 双击 `Start.bat`（或 `启动.bat`）。
3. 浏览器打开后，填入 DeepSeek API Key，点「保存并开始」。
4. 左侧打开「技能库」选一个技能，或直接把问题/报表丢进输入框。

> Key 在 <https://platform.deepseek.com/api_keys> 创建，按量计费。每次回答下方会显示本次 token 用量。
>
> 默认白色主题；在「设置 → 配色」里可以切换黑色主题，或跟随系统。

**不需要安装 Node、Python 或任何其他环境**，运行时已经打包在 `runtime/` 里。

## 能做什么

- **读材料**：Excel、PDF、Word、PPT、图片直接上传，模型读内容，不用先转格式。
- **联网查**：打开「联网」后，需要最新政策、费用或趋势时搜索，并附来源。
- **查数据源**：连接领星、卖家精灵、SIF、Sorftime 等 MCP 后，技能可以直接查类目、关键词、销量和广告数据。
- **算账**：利润、ACOS、补货点这类数字用代码算，过程可复核。计算在受限子进程里跑：只能读写 `workspace/`，禁止联网、子进程和访问系统其他文件。
- **交付文件**：生成的 Listing、报告、CSV 落在 `workspace/`，在对话里直接「打开 / 下载」。
- **按流程走**：每个技能有固定的输入清单、分析框架、输出格式和红线，不是一句万能提示词。

## 数据源（MCP）

左侧「数据源」可以连接：

| 预设 | 用途 | 认证 |
|---|---|---|
| 领星 ERP | 订单、库存、广告等运营数据 | Bearer Token（以服务商为准） |
| 卖家精灵 | 类目、关键词、竞品数据 | Bearer Token（以服务商为准） |
| SIF | 亚马逊市场与关键词数据 | Bearer Token（以服务商为准） |
| Sorftime | 类目报告、Top100、关键词与趋势 | URL 参数 `key`（地址已预填 `https://mcp.sorftime.com`） |
| 自定义 MCP | 任意 HTTP MCP 服务 | Bearer / URL 参数 key / 自定义 Headers |

步骤：

1. 打开「数据源」→ 找到对应卡片 → 配置。
2. 填 MCP 地址和 Key。地址、Key 以服务商控制台为准，不要照抄别人的。
3. 点「保存并测试」，成功后会显示读到的工具数量和工具名。
4. 勾选「启用」，回到对话。模型会看到 `mcp__...` 开头的工具，在需要真实数据时调用。

说明：

- 目前支持 **HTTP MCP（Streamable HTTP，JSON 或 SSE 响应）**。纯 SSE 长连接或本地 stdio 的 MCP 还需要额外适配。
- 配置保存在本机 `data/mcp.json`，不会发给模型；但 MCP 工具返回的数据会进入对话并发送到 DeepSeek，敏感字段请先在服务商侧脱敏。
- 工具名会带数据源前缀，例如 `mcp__sorftime__category_report`，方便在运行记录里看出数据来源。

## 数据与隐私

- API Key 存在**本机浏览器**的 localStorage，不上传到任何第三方服务器。
- 对话记录存在本机 `data/`，MCP 配置存在 `data/mcp.json`，生成的文件在 `workspace/`。
- 请求从本机直接发往 `api.deepseek.com`，没有中间服务器。
- 发给模型的内容（提问、附件）会离开本机，敏感信息请先脱敏。
- 换电脑：把整个文件夹复制过去（连同 `data/` 和 `workspace/`），对话、MCP 配置和文件都在。

## 分发给他人的正确方式

1. 先清空自己的数据（设置 → 数据 → 清空；或删除 `data/`、`workspace/` 里的内容）。
2. 把**整个文件夹**压缩成 zip 发给对方。
3. 对方解压后双击 `Start.bat`，填自己的 Key。

注意：

- **不要把 Key 写进 `config.json` 再发出去**，任何人解压都能看到。
- 不要把 `data/`（对话和 `mcp.json` 里的 Key）、`workspace/`（你的文件）打包进去。
- 对方电脑需要 Windows 10/11；当前包里的 `runtime/node.exe` 是 Windows 版。

## 自定义

编辑 `config.json`：

```json
{
  "brand": "跨境 AI 工作台",
  "brandEn": "Ecom Workbench",
  "tagline": "……",
  "port": 7871,
  "apiBase": "https://api.deepseek.com",
  "model": "deepseek-flash",
  "maxSteps": 24
}
```

- `brand`：左上角名称，也是发给模型的角色名。
- `port`：默认 7871，被占用会自动往后找。
- `model`：默认 `deepseek-flash`；也可以在界面设置里切 `deepseek-v4-pro`。

加自己的技能：见 [`docs/如何添加技能.md`](docs/如何添加技能.md)。技能用 `SKILL.md` + `skill.json`，和 DSH 的技能格式兼容。

界面设计说明（配色、编号、间距规则）见 [`docs/设计说明.md`](docs/设计说明.md)。

## 常见问题

**Key 无效 / 余额不足**
到 platform.deepseek.com 检查 Key 和余额；设置里点「测试连接」可直接验证。

**连不上接口**
公司网络/代理可能拦截 `api.deepseek.com`。换网络，或在系统代理里放行。

**浏览器没自动打开**
手动打开窗口里显示的地址（默认 <http://127.0.0.1:7871>）。

**端口被占用**
会自动换到 7872、7873……看窗口里的实际地址。

**杀毒软件拦截**
`runtime/node.exe` 是 Node.js 官方运行时，可能被误报。把整个文件夹加入信任即可。

**Excel 上传后读不到内容**
优先 `xlsx`；老式 `xls` 或加密文件先另存为 `xlsx`/`csv`。超大文件建议先删掉无关列。

**对话记录存在哪**
`data/sessions/`、`data/mcp.json`；生成文件在 `workspace/`；删除文件夹即可重置。

**能不能多人共用**
这是本机单用户工具，服务只监听 `127.0.0.1`，同一局域网的其他设备访问不到。要多人用，每人下载一份、各填各的 Key。

## 目录结构

```
EcomWorkbench/
├─ Start.bat / 启动.bat     启动器
├─ config.json              品牌与默认配置
├─ server/                  本地服务（Node，无第三方依赖；含 MCP 客户端）
├─ app/                     聊天界面、技能库页、数据源页
├─ skills/                  15 个可用技能（构建时从 ecom-skills 快照）
├─ runtime/node.exe         内置运行时
├─ workspace/               AI 生成的文件
├─ data/                    对话、附件、MCP 配置（mcp.json）
└─ docs/                    说明文档
```

## 版本

**v1.6.20 · 2026-11**

最近几个版本加了这些：

- **员工（Agent）**：选品 / 上架 / 广告 / 经营四位，各自带一套岗位技能；也可以不选员工，直接在技能库里用单个技能。
- **技能与员工分离**：技能是独立文件夹，员工只是引用技能 id；给员工加能力＝加一个 id。
- **配置面板**：亚马逊周报这类有配置的技能，可以在界面里增删复盘产品、改父体 ASIN / 竞品 / 目标成本，不用手改 JSON。
- **AI 改配置**：对话里说「把 66D38 的竞品换成 X」，模型提改动清单，你点「应用」才写盘。
- **数据源凭据自动注入**：在「数据源」里配好领星 / SIF / SORFTIME，技能脚本直接拿到，不用再填 .env。
- **应用内更新**：设置或「说明」里能检查新版本、下载、自动重启；有新版本会在「说明」上亮红点。
