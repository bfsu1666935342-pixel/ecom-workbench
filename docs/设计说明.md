# 工作台界面设计说明

这次界面整理用了 [unslop](https://github.com/heydamir/unslop) 的方法：先找 AI 味的来源，再从产品本身定方向，按「间距 → 色彩 → 图标 → 文案 → 字体 → 布局 → 细节 → 视觉 → 动效」逐层修。第二轮又把配色从暖纸 + 绿色改成了黑白，参考 Apple 的克制感，但没有使用 Apple 的字体文件、图标或素材，也不代表与 Apple 有任何关联。

## 方向（五行）

- **Product**：中国卖家的本地亚马逊运营工作台，15 个可用技能读报表、算账、写交付文件。
- **Character**：平静、准确、克制（calm, precise, understated）。
- **World**：白纸、黑墨、灰色层级和细线；像一张干净的运营台账，而不是彩色仪表盘。
- **Moments**：首页的编号技能索引；对话里的工具运行记录和文件产出。
- **Signature**：每个技能在所属分组内独立编号（01、02…），弹窗和对话顶栏带上分组名，避免跨组重号。

## 审计：修改前的问题

- 暖纸底色 + 绿色强调色，颜色偏「环保/茶饮」，不像专业工具。
- 顶部有径向色晕，卡片有悬浮位移和阴影，偏营销页。
- 巨幅问候式标题「今天，先推进哪件事？」和「不只是陪你聊」的对比句。
- 技能、工具栏、文件、提示都用 emoji 当图标，尺寸和颜色不统一。
- 四张等宽功能卡，emoji + 标题 + 一句虚话，属于模板化空状态。
- 绿色铺在技能、来源、文件类型、横幅、按钮上，重点不突出。
- 间距混用 15/13/11/9/7/5/3px，圆角混用 20/17/15/12/10/8/6/5px。
- 标题字重 700–750，小字带负字距；多处大写字距标签。
- 工具步骤是胶囊，来源徽标是彩色，卡片 hover 会抬起并出现箭头。
- 设置页的「测试连接」孤零零挂在行外；首次使用页也是营销式大标题。

## 九轮修改

1. **间距**：统一到 4px 节奏。侧栏行高 34，索引行高 44，卡片内边距 16–24，页面边距 32–40；同一组内的间距小于组间。
2. **色彩**：改成黑白灰。页面白色，侧栏 `#f5f5f7`，卡片白色，文字 `#1d1d1f`，次级 `#6e6e73`；边框是 8% 黑发丝线。主按钮黑色（深色主题白色），蓝色只用于链接和焦点，绿色全部移除。深色主题是纯黑页面 + `#1c1c1e` 卡片 + 白色主按钮。
3. **图标**：移除界面里的全部 emoji。统一用 16–18px、1.5 描边的线性图标；技能不再用图标，改用编号。
4. **文案**：标题从问候句改成「选一个技能」；删掉对比句、感叹号和「三步上手，剩下的交给我」；费用说明改成「按量计费，用量显示在回答下方」。
5. **字体**：优先 Apple 系统字体（`-apple-system` / SF Pro），Windows 回退 Segoe UI / 微软雅黑。标题 600，正文 400/500；大标题轻微负字距，小字零字距；数字统一等宽、tabular。
6. **布局**：侧栏只放「技能库」「数据源」两个入口和最近对话；技能库独立成页，带搜索和分组筛选；首页只保留「开始处理」和「浏览技能库」；数据源单独成页。侧栏 276px，内容 920px，页面边距 32–40。
7. **细节**：圆角收敛到 4/8/10/14/18；工具步骤从胶囊改成带细线的运行记录；来源和文件类型改中性底；黑色主按钮，蓝色文字链接；弹层 18px 圆角、8px 背景模糊。
8. **视觉**：不加装饰图。技能库的「编号 + 分组线 + 简短说明」和对话里的工具记录是两处视觉重点；数据源页用中性卡片和状态点。
9. **动效**：去掉卡片抬升、箭头滑入和逐条入场；只保留弹层淡入、按下 0.99 缩放、加载旋转和流式光标。

## Apple-like 的具体做法

- 白底、灰侧栏、黑字；深色模式反过来是纯黑、深灰卡片、白字。
- 主按钮用黑色/白色，不用彩色；链接用系统蓝 `#0066cc`（深色 `#2997ff`）。
- 大标题 30px、轻微负字距；正文 14–15px；灰色只分三级。
- 大量留白，发丝线分隔，卡片 14px 圆角，弹层 18px。
- 侧栏选中是浅灰填充，不做彩色高亮，不加左侧色条。
- 去掉渐变、发光、彩色阴影、emoji 和装饰图形。
- 输入框聚焦用细黑边和很淡的外圈；链接和复选框用系统蓝。

## 结果

- 默认白色主题；设置 → 配色可切换黑色主题，也可跟随系统。
- 首页只留「开始处理」和技能库入口；技能库是独立页面，编号与分组一致。
- 数据源页支持领星、卖家精灵、SIF、Sorftime 预设和自定义 MCP，显示连接状态与工具数量。
- 所有 emoji 从界面移除；技能编号成为产品独有的识别细节。
- 设置页、技能弹窗、数据源弹窗、首次连接页统一到同一套标题、表单和按钮规格。
- 移动端技能索引收起描述，只保留编号与标题，行高一致。

## 验证

- Chrome 无头渲染：1440×960 浅色 / 深色、414×896 移动端，控制台无异常。
- 端到端：技能加载、流式对话、思考、联网来源、附件、写文件、历史回放、设置保存。
- MCP：保存、连接测试、工具列表、模型调用 `mcp__...` 工具、数据源计数。
- 打包后在干净目录解压启动，首页、技能库、数据源、对话和文件产出均正常。
