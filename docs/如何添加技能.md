# 如何添加 / 修改技能

技能 = 一段写给模型的「岗位说明书」+ 一点界面元数据。放进 `skills/` 后重启 `Start.bat` 就会出现在左侧技能库。

## 目录结构

```
skills/
└─ my-skill/
   ├─ SKILL.md      # 必填：技能说明（给模型看）
   └─ skill.json    # 建议填：标题、分组、常用问法、表单字段（给界面看）
```

`skill.json` 可以省略；省略时用 `SKILL.md` frontmatter 里的 `name`、`description` 和一级标题。界面按排序自动生成编号（01、02…），不再使用图标。

## skill.json

```json
{
  "id": "my-skill",
  "title": "我的技能",
  "group": "选品与市场",
  "order": 200,
  "tagline": "一句话说明这个技能解决什么问题",
  "description": "点开技能卡片时显示的详细介绍，2–3 句。",
  "starters": [
    "帮我做……",
    "看看这个……"
  ],
  "fields": [
    {
      "key": "product",
      "label": "产品 / 类目",
      "type": "text",
      "placeholder": "例如：便携露营灯，美国站",
      "required": true
    },
    {
      "key": "detail",
      "label": "补充信息",
      "type": "textarea",
      "placeholder": "……"
    }
  ]
}
```

- `id`：英文、短横线，和文件夹名一致最好。
- `title`：左侧技能库和首页索引里显示的名称。
- `group`：左侧分组名；新分组会自动出现。
- `order`：数字越小越靠上；每个分组内从 01 开始独立编号，按 `order` 排序。
- `tagline`：首页索引里的一句话说明。
- `starters`：技能弹窗里的「常用问法」，点击后填入输入框。
- `fields`：会渲染成技能弹窗里的表单；用户填了就会拼进提问。`type` 支持 `text` / `textarea`。
- `icon` / `featured`：旧版界面字段，当前版本不再使用，可以删掉。

## SKILL.md

````markdown
---
name: my-skill
description: "用一句话说明什么时候用这个技能，写给模型做路由判断。"
---

# 我的技能

## 适用场景
- ……

## 先收信息
1. ……
2. ……

## 处理流程
### 1. ……
……

## 输出格式

```markdown
## 结论
……
```

## 红线
1. 不编数据。
2. ……
````

`SKILL.md` 的正文会被完整拼进系统提示词（选中该技能时）。写法建议：

- **先收信息**：明确要问哪几项；信息不全时怎么降级处理。
- **处理流程**：分步骤，每步给判断标准或公式。
- **输出格式**：给一个模板，模型会照做，界面也能渲染表格。
- **红线**：不编数字、不承诺结果、合规边界。
- 长度控制在 1500–3000 字；太长会占上下文，太短会空泛。

## 让技能真的「动手」

技能正文里可以直接要求模型使用内置工具：

- `web_search` / `read_url`：联网查资料、读网页（需要用户打开「联网」）。
- `read_file` / `list_files`：读工作区文件（用户上传的附件在 `attachments/`）。
- `write_file`：把结果写成文件，例如 `reports/xxx.md`。
- `run_javascript`：跑 Node 代码做精确计算；内置 `read()`、`readCsv()`、`write()`、`readJson()`、`list()`、`table()`。

## 和 DSH 技能兼容

`SKILL.md` 使用标准 frontmatter（`name` + `description`），把整个技能文件夹复制到 DSH 的 skills 目录也能直接被 DSH 识别：

```
D:\.dsh\skills\my-skill\
```

DSH 会读 `SKILL.md` 的正文和 frontmatter；`skill.json` 只影响这个工作台的界面展示。

## 改完怎么生效

关闭运行窗口 → 重新双击 `Start.bat`。技能只在启动时加载。

如果新增后没出现：检查 `skills/<目录>/SKILL.md` 是否存在、`skill.json` 是否是合法 JSON（不能有尾逗号）。
