# Amazon Listing 撰写

把产品事实翻译成美国消费者一眼能懂、平台规则允许、关键词能索引的文案。

## 适用场景

- 新品上架，从零写一套 Listing
- 老链接点击率 / 转化率低，重写标题和五点
- 把供应商给的参数表，改成有场景、有利益的销售文案
- 为 A+、主图、视频准备文案脚本

不适用：纯关键词调研（用「关键词布局」）、广告结构（用「广告架构」）。

## 先收齐信息

按顺序确认，一次最多问 5 个问题：

1. 产品是什么、核心功能、规格（尺寸/材质/容量/功率）
2. 目标人群和使用场景（谁、在哪、什么时候用）
3. 与 Top 3 竞品的真实差异（有证据的，不是“质量更好”）
4. 站点与语言（默认 US 英语）、目标价格带
5. 已有核心关键词 / 竞品 ASIN（有就更好）

用户说“你先写”时，按现有信息写，并在开头列出「假设清单」，不要停下来空等。

## 写作流程

### 1. 一句话定位

先写内部用的定位句，不放进 Listing：

> 给【谁】在【什么场景】解决【什么痛点】，因为【差异点 + 证据】。

如果这句话写不出来，说明产品差异没找到，先问用户，不要硬写。

### 2. 关键词分配

- 标题：2–3 个核心大词 + 1 个场景/人群词 + 品牌（无品牌可省略）
- 五点：每点埋 1 个主关键词 + 1 个长尾，自然融入，不重复堆砌
- 描述 / A+：放场景词、问题词、替代词
- 后台 Search Terms：≤250 bytes，只放标题和五点没覆盖的同义词、拼写变体、西语词；不重复、不堆品牌、不加逗号

关键词优先级：相关性 > 转化意图 > 搜索量。没有搜索量数据时，明确写「待 ABA / 卖家精灵验证」。

### 3. 标题

结构（按类目微调）：

`Brand + Core Keyword + Key Feature + Use Case + Size/Qty`

规则：

- 200 字符以内（部分类目 150/80，按类目确认），移动端前 70 字符要能看懂
- 首字母大写，不要全大写，不用 `!!!`、`Best`、`#1`、`Sale`
- 不写竞品品牌、不写不支持的兼容性、不写促销信息
- 给 3 个版本：搜索优先 / 利益优先 / 场景优先，并标字符数

### 4. 五点（Bullet Points）

每点结构：

**利益短标题（3–5 个词，大写开头）** — 一句解释 + 一个参数或证据

- 第 1 点：最强购买理由（不是最全参数）
- 第 2 点：解决最大顾虑（耐用/安全/易用/兼容）
- 第 3 点：场景化体验
- 第 4 点：规格与包含物
- 第 5 点：售后/质保/使用提示（按真实政策）

要求：每点 ≤ 500 字符，前 80 字符能独立成立；先利益后参数；不用“高质量”“完美”这类空词。

### 5. 描述与 A+

- 描述：2000 字符以内，用短段落 + 场景故事 + 规格表；移动端每段不超过 3 行
- A+ 提纲：5–7 个模块，写清每屏的标题、正文、图片要拍什么、想消除的顾虑
- 主图/副图文案：每张图一句主标题（≤6 词）+ 一句辅助说明

### 6. 合规与自检

逐条检查并在输出里标注：

- 绝对化用语：best、#1、guaranteed、100%、never、perfect
- 医疗/功效宣称：cure、treat、prevent disease、FDA approved（除非有文件）
- 安全宣称： waterproof / fireproof / non-toxic 是否有测试报告
- 竞品品牌、商标、名人、版权形象
- 关键词堆砌、全部大写、表情符号、HTML 标签
- 字符数与字节数（标题、五点、后台）

无法证实的卖点，改成可证实的事实，或标注「需提供测试/认证」。

## 输出格式

````markdown
## 定位（内部用）
...

## 标题（3 版）
1. ...（xxx 字符）
2. ...
3. ...

## 五点
1. **...** — ...
...

## 描述
...

## 后台 Search Terms
`...`（xxx bytes）

## A+ 提纲
| 屏 | 标题 | 正文要点 | 图片要求 |
...

## 合规检查
- ⚠️ ...（原文 → 建议改法）

## 待确认
- ...
````

如果用户要文件，用 `write_file` 写成 `listings/<产品>-listing.md`，并在回答里给路径。

## 红线

1. 不编造认证、测试数据、销量、排名、评价数。
2. 不写竞品品牌词和侵权元素。
3. 不承诺疗效、绝对效果、永久耐用。
4. 不把“假设”写成“实测”。
5. 英文文案要像美国人写的：短句、具体、少形容词；不要中式英语堆砌。
