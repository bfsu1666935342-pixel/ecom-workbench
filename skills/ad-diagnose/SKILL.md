# 广告数据诊断

拿报表说话。没有报表就先要报表，不靠感觉优化。

## 适用场景

- 搜索词报告出来一堆词，不知道先动哪个
- ACOS 高、花费快，但不知道钱花在哪
- 自动 campaign 跑了两周，不知道怎么收割
- 月底复盘，要给团队一个行动清单

不适用：还没开广告、要搭结构（用「广告架构与预算」）。

## 先要数据

最少给我一份**搜索词报告**（CSV/Excel），字段尽量包含：

`Campaign Name, Ad Group, Match Type, Search Term, Impressions, Clicks, Spend, Sales, Orders, Units`

可选：广告活动报告、placement 报告、业务报告（CVR）、目标 ACOS/CPA、客单价、毛利率。

拿到文件后：

1. 用 `readCsv()` 读取，先报「行数、时间范围、花费合计、销售合计」，确认口径。
2. 字段名中英文都可能，做一次映射并在输出里写明。
3. 数据少于 7 天或点击少于 100 时，提示结论仅供参考。

## 诊断逻辑

### 1. 算指标

对每个搜索词：

```
CTR = Clicks / Impressions
CPC = Spend / Clicks
CVR = Orders / Clicks
ACOS = Spend / Sales
ROAS = Sales / Spend
```

### 2. 分四类处理

| 类型 | 条件（示例） | 动作 |
|---|---|---|
| 浪费 | 花费 ≥ 2× 目标 CPA 且 0 单；或 ACOS ≥ 2× 目标 | 否定 / 降价 / 暂停 |
| 观察 | 有点击、0 单，花费未到阈值 | 加否定词根，再观察 7 天 |
| 收割 | 有单、ACOS ≤ 目标，且是长尾 | 提价 / 单独精准 / 加预算 |
| 放量 | 有单、ACOS 低、曝光受限 | 加预算、Top 位加价、扩变体 |

### 3. 结构问题

- 自动 campaign 是否一直没否词 → 浪费
- 精准 campaign 是否内部抢量（同词多匹配）
- 品牌词是否和品类词混在一起 → ACOS 失真
- 预算是否总在中午烧完 → 错过转化时段
- 高 CTR 低 CVR → 先查 Listing/价格/评论，不是继续加价

### 4. 排序

按「可节省金额」排序，而不是按 ACOS 高低：

`影响金额 = 该词花费 - 该词应花费（按目标 ACOS）`

先动影响金额最大的 10 个词。

用户要文件时，用 `run_javascript` 生成 `reports/ad-diagnosis.csv`（逐词明细）和 `reports/ad-diagnosis.md`。

## 红线

1. 只基于报表里的真实行，不编数字；先报行数和合计。
2. 注意归因延迟（通常 7–14 天），别把刚花的钱判死刑。
3. 分清「词的问题」和「Listing 的问题」：高点击低转化先查 Listing。
4. 不建议恶意点击竞品、刷单、违规操纵评论。
5. 建议要能落地到后台：否词、出价、预算、匹配方式，写具体值。
