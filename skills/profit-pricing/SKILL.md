# 利润与定价

很多链接不是卖不动，是**卖得越多亏得越多**。先把单件账算到分。

## 适用场景

- 新品定价，不知道定多少既有竞争力又有利润
- 准备降价/涨价/上 Coupon，想先看影响
- 老板问“这个品到底赚不赚钱”
- 广告 ACOS 目标定多少才合理

不适用：广告结构（用「广告架构与预算」）；类目整体评估（用「类目深度评估」）。

## 先收数字

逐项确认，缺失就标「假设」并给区间：

| 项目 | 说明 |
|---|---|
| 售价 | 当前或计划 |
| 采购成本 | 含税/不含税要说明 |
| 头程 | 海运/空运/快递，单件摊 |
| FBA 配送费 | 按尺寸重量、当前费率 |
| 佣金 | 通常 15%，部分类目不同 |
| 退货率 | 退货处理费 + 不可售损耗 |
| 仓储/库存费 | 旺季附加费 |
| 广告占比 | 或目标 ACOS |
| Coupon/促销 | 折扣、秒杀费 |
| 汇率/支付/税 | 需要时 |

费率会变，先让用户确认当前站点费率；没有就用最近公开数据并标注。

## 计算

### 单件 P&L

```
净利 = 售价
     - 采购 - 头程 - FBA - 佣金
     - 退货摊销（售价 × 退货率 × 损耗系数）
     - 仓储 - 促销 - 广告
```

```
净利率 = 净利 / 售价
广告前毛利 = 售价 - 采购 - 头程 - FBA - 佣金 - 退货 - 仓储 - 促销
盈亏平衡 ACOS = 广告前毛利 / 售价
```

### 价格阶梯

给 3–5 个价格点（如 $24.99 / $27.99 / $29.99 / $32.99），每个价格点算：

- 净利率
- 盈亏平衡 ACOS
- 在目标 ACOS 下的净利
- 相比当前价的销量弹性假设（没有数据就说明是假设）

### 敏感性表

行：售价；列：广告占比（0% / 10% / 15% / 20% / 25%）；单元格：净利率。用 `run_javascript` 生成 HTML/CSV 表格。

## 红线

1. 不编费率、汇率、退货率；查不到就让用户填。
2. 所有假设单独列，不混进“实测”。
3. 不把“净利”算成“毛利”，不遗漏退货和仓储。
4. 不承诺涨价后销量不变。
5. 涉及税务/合规，提示咨询当地专业机构。
