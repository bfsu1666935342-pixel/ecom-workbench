# 广告架构与预算

先把账算清楚，再决定开几个 campaign。广告不是越复杂越专业，而是每一层都有明确任务。

## 适用场景

- 新品准备开广告，不知道开几个、怎么分预算
- 老品 ACOS 失控，想重构结构
- 要说服老板批预算，需要一套可解释的模型
- 从自动打到手动，不知道怎么过渡

不适用：已经有搜索词报告要做止损（用「广告数据诊断」）；Listing 转化问题（先查 Listing）。

## 先收数字

缺一项就先问，不要拍脑袋：

1. 售价、采购成本、头程、FBA 费、佣金（按站点当前费率）
2. 退货率、仓储费、Coupon/促销成本
3. 目标净利率（或能接受的最大 ACOS）
4. 日预算 / 月预算
5. 新品还是老品、当前 CVR、类目 CPC 区间（有数据更好）

## 第一步：算三个数

### 1. 广告前毛利率

```
毛利率 = (售价 - 采购 - 头程 - FBA - 佣金 - 退货摊销 - 仓储) / 售价
```

### 2. 盈亏平衡 ACOS

```
盈亏平衡 ACOS = 广告前毛利率
目标 ACOS = 广告前毛利率 - 目标净利率
```

### 3. 盈亏平衡 CPC

```
盈亏平衡 CPC = 售价 × 毛利率 × CVR
```

如果实际 CPC 高于这个数，要么提 CVR（Listing/价格/评论），要么换更精准的词，要么这个品不适合打广告。

用 `run_javascript` 算，保留两位小数，输出表格。

## 第二步：搭结构

新品期（0–8 周）建议 4 层，别一上来开 10 个：

| 层 | Campaign | 任务 | 预算占比 | 出价 |
|---|---|---|---|---|
| 探索 | SP-AUTO-Discovery | 跑词、跑 ASIN | 20% | 建议价 80% |
| 核心 | SP-EXACT-Core | 打 S 级词，抢排名 | 45% | 建议价 100–120% |
| 扩展 | SP-PHRASE-Longtail | 收长尾、控 ACOS | 25% | 建议价 90% |
| 竞品 | SP-ASIN-Competitor | 定投弱竞品详情页 | 10% | 建议价 100% |

稳定期再考虑：SB 品牌词防守、SBV 视频、SD 再营销/ASIN 扩量。

### 命名规则

`站点-类型-匹配-任务-版本`，例如 `US-SP-EXACT-Core-v1`。改名会丢历史，定好别乱动。

### 出价与位置

- 初始出价：类目建议价的 70–100%，别一上来顶格
- Top of Search 加价：先 0%，有 2 周数据后按 ACOS 调，单次不超过 +30%
- 预算：单 campaign 至少能支撑 10–15 次点击/天，否则数据太慢
- 竞价策略：新品先用“动态竞价-仅降低”，有稳定转化后再试“提高和降低”

## 第三步：否词与止损

- 自动/广泛跑 7 天后，把「高点击 0 单」的词否掉
- 精准 campaign 内否掉不相关词，避免内部抢量
- 品牌词单独开，不和品类词混
- 设止损线：单 campaign 花费 ≥ 2× 目标 CPA 且 0 单 → 降价/否词/暂停

## 第四步：30 天节奏

| 阶段 | 动作 | 看什么 |
|---|---|---|
| D1–7 | 不开新 campaign，收数据 | 曝光、CTR、CPC、搜索词 |
| D8–14 | 否词、加精准、调预算 | 浪费花费、出单词 |
| D15–21 | 放量赢家、加 ASIN 定投 | ACOS、CVR、自然排名 |
| D22–30 | 评估 TACoS、砍尾部 | 总广告占比、利润 |

用户要文件时，写成 `reports/<产品>-ad-plan.md`，并可用 `run_javascript` 生成预算 CSV。

## 红线

1. 不编 CPC、CVR、类目建议价；没有就给区间并标“假设”。
2. 费率必须按站点当前标准，提醒用户核对。
3. 不承诺 ACOS/排名结果。
4. 不建议刷点击、恶意否定竞品、违规操纵。
5. 结构方案要能落地到后台，别给一堆执行不了的概念。
