# 流量承接诊断

同一个 ACOS 差，可能是三种完全不同的病：**没曝光、没点击、没转化**。用药完全不同。

## 适用场景

- 广告花了钱，但不知道卡在哪一环
- 某些词曝光低，要不要加价抢位置
- 点击率低，是不是主图/价格问题
- 转化率低，是不是 Listing/评论/预期问题
- 要逐词给运营动作，而不是一句“优化 Listing”

不适用：整体广告结构（用「广告架构与预算」）；纯否词止损（用「广告数据诊断」）。

## 先要两份数据

1. **搜索词报告**：Search Term、Impressions、Clicks、Spend、Orders、Sales
2. **搜索量词库**：关键词、月搜索量（ABA / 卖家精灵 / 西柚导出）

把两份按搜索词合并。没有词库时，只能看 CTR/CVR，不能算覆盖率 k。

## 核心指标

对每个词：

```
曝光覆盖率 k = 广告曝光 / 月搜索量
CTR = Clicks / Impressions
CVR = Orders / Clicks
CPA = Spend / Orders
```

k 的口径要说清楚：是「广告曝光 / 月搜索量」，不是市场份额；只用于同词横向比较和趋势判断。

## 四象限判断

| 现象 | 判断 | 动作 |
|---|---|---|
| k 低（< 5%） | 没被看到 | 提 bid / 加预算 / 换匹配 / 抢 Top 位 |
| k 正常，CTR 低（< 0.3%） | 看到了不点 | 主图、价格、Coupon、标题、评分 |
| CTR 正常，CVR 低 | 点了不买 | Listing、A+、评论、尺寸/预期、配送 |
| CVR 正常，CPA 高 | 买得太贵 | 降价 bid、否词、提客单、换词 |

阈值按类目调整，先看本品类的均值，不要硬套。

## 逐词输出

每个重点词给：

- 指标：曝光、点击、CTR、CVR、CPA、k
- 诊断：没看到 / 不点 / 不买 / 太贵 / 健康
- 动作：具体到「加价多少、改哪张图、否哪个词、补什么评论」
- 优先级：按可提升的订单量排序

## 输出格式

````markdown
## 数据口径
搜索词报告 xx 行，词库 xx 词，匹配上 xx 词；时间 xx–xx

## 一句话结论
最大漏点在「看到了不点」：xx 个词 CTR < 0.3%，合计曝光 xx。

## 逐词诊断
| 关键词 | 曝光 | k | CTR | CVR | CPA | 诊断 | 动作 | 优先级 |
|---|---|---|---|---|---|---|---|---|

## 三类问题汇总
### 没被看到（k 低）
- ...
### 看到了不点（CTR 低）
- ...
### 点了不买（CVR 低）
- ...

## 7 天动作
1. ...
2. ...

## 数据缺口
- 缺 xx 词搜索量，k 无法计算
````

要文件时用 `run_javascript` 生成 `reports/<产品>-traffic-diagnosis.csv`。

## 红线

1. 不编搜索量、曝光、点击；先报匹配率。
2. k 的口径必须写清楚，不夸大解释。
3. 不把 Listing 问题全推给广告。
4. 不建议恶意点击、刷曝光。
5. 样本太小时（点击 < 50）只给方向，不下强结论。
