# 关键词调研与布局

关键词不是列得越多越好，而是**每个词都有明确的位置和用途**。

## 适用场景

- 新品上架前，确定核心词、长尾词、广告词
- 老品流量下滑，检查关键词覆盖缺口
- 拿到 ABA / 卖家精灵 / 西柚 / 搜索词报告，不知道怎么用
- 为标题、五点、后台、广告分配词

不适用：已经拿到搜索词报告要做广告诊断（用「广告数据诊断」）。

## 先收齐信息

1. 产品、核心卖点、目标站点
2. 种子词（3–10 个）或竞品 ASIN
3. 已有数据：ABA 排名、搜索量、点击集中度、竞品反查词（有就上传/粘贴）
4. 新品还是老品、当前广告结构

**没有搜索量数据时，不要编数字。** 用相对优先级（高/中/低）和「待验证」标注，并告诉用户去哪里导出。

## 分析流程

### 1. 建词库

把词按意图分 6 类：

| 类型 | 例子 | 用途 |
| --- | --- | --- |
| 核心品类词 | camping lantern | 标题、主广告、排名 |
| 属性/规格词 | usb rechargeable lantern | 标题、五点、精准广告 |
| 场景/人群词 | lantern for power outage | 五点、描述、场景广告 |
| 问题/痛点词 | bright lantern for tent | 五点、A+ |
| 竞品/替代词 | 相似产品名（不写品牌） | 广告 ASIN/词投放、对比文案 |
| 拼写/同义词 | lanter, lamp | 后台 Search Terms |

每个词记录：意图、相关性（1–5）、估算量级、竞争度、当前排名、来源。

### 2. 选词

优先级 = 相关性 × 购买意图 × 可打性

- **S 级（3–5 个）**：核心大词，必须进标题和主广告
- **A 级（10–20 个）**：精准长尾，进五点和手动精准
- **B 级（20–50 个）**：场景/问题词，进描述、A+、广泛/词组
- **C 级**：只放后台或否定，不浪费广告预算

判断可打性：头部是否被少数 ASIN 垄断、评论门槛、价格带是否匹配。没有数据就明说。

### 3. 分配位置

- 标题：S 级 2–3 个，自然可读，不堆砌
- 五点：每点 1 个 A 级主词 + 1 个 B 级长尾
- 描述 / A+：B 级、问题词、替代词
- 后台 Search Terms：≤250 bytes，只放没覆盖的同义词/拼写/西语，不重复标题
- 广告：S 级投精准 + 词组；A 级精准；B 级广泛/自动；C 级否定

### 4. 排 4 周推进节奏

| 周 | 动作 | 观察指标 |
| --- | --- | --- |
| W1 | 标题/五点/后台更新，开精准 | 索引、曝光 |
| W2 | 自动 + 词组扩词，收搜索词 | 新词、CTR |
| W3 | 否词、加价、加精准 | CVR、ACOS |
| W4 | 冲排名词加大预算，评估自然位 | 自然排名、TACoS |

## 输出格式

````markdown
## 词库总览
共 xx 个词：S 级 x / A 级 x / B 级 x / C 级 x
数据来源：ABA（xx 周）/ 卖家精灵 / 搜索词报告（xx 行）

## 核心词表
| 关键词 | 类型 | 相关性 | 量级 | 竞争 | 放哪里 | 广告匹配 |
|---|---|---|---|---|---|---|

## 标题建议
...

## 后台 Search Terms
`...`（xx bytes）

## 广告词包
- 精准：...
- 词组：...
- 广泛/自动：...
- 否定：...

## 4 周计划
...

## 数据缺口
- 缺 xx 的搜索量，建议从 ABA 导出后我再补
````

用户要文件时，用 `write_file` 生成 `keywords/<产品>-keyword-map.md` 或 CSV。

## 红线

1. 不编搜索量、ABA 排名、竞品出单词。
2. 不把竞品品牌词写进文案或后台。
3. 不为了覆盖把标题写成关键词堆砌。
4. 不承诺“上首页”“打爆”。
5. 数据来源要写清楚（样本/周次/站点）。
