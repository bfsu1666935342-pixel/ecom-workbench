# 合规与风控检查

合规不是“写得保守一点”，而是**每一句宣称都要有依据**。这份检查帮你排雷，不替代律师或平台官方判定。

## 适用场景

- 新品 Listing 上线前自检
- 收到绩效通知/下架警告，想定位问题
- 改文案、改图片、改包装前排查
- 准备认证/检测资料清单

不适用：已经收到正式侵权投诉/法律函件（建议直接找专业律师）。

## 先收材料

1. 站点（US/UK/DE…）
2. 类目与产品
3. 完整 Listing 文案（标题、五点、描述、A+、后台词）
4. 图片文案（主图/副图/包装）
5. 已有的认证、检测报告、专利/商标信息
6. 是否收到过警告/投诉

## 风险类别

### 1. 绝对化与效果宣称

- `best`, `#1`, `top rated`, `guaranteed`, `100%`, `never`, `perfect`, `lifetime`
- “永久耐用”“绝对不会坏”“一劳永逸”
- 无法验证的比较级：`better than [竞品]`

处理：删掉，或改成可验证的事实（`up to X hours`、`tested to 10,000 cycles`，前提是有测试）。

### 2. 医疗/健康/功效

- `cure`, `treat`, `prevent`, `heal`, `antibacterial`, `anti-inflammatory`
- 减肥、助眠、缓解疼痛、提升免疫
- `FDA approved` / `clinically proven`（除非真有对应文件）

处理：删除功效；只描述产品物理功能；需要时走医疗器械/膳食补充剂合规路径。

### 3. 安全与认证

- `waterproof` / `fireproof` / `non-toxic` / `food grade` / `BPA free`
- `UL listed` / `FCC` / `CE` / `RoHS` / `CPSIA` / `Prop 65`
- 儿童产品、电器、电池、化妆品、食品接触材料

处理：没有报告就不要写；有报告要确认型号/批次一致；儿童产品注意 CPSIA 和警告标签。

### 4. 知识产权

- 竞品品牌名、Logo、角色形象、名人肖像
- 外观专利、实用专利、商标（尤其图形商标）
- “Compatible with X” 可以，但不能暗示官方授权
- 图片盗用、字体版权、音乐版权

处理：去掉品牌词和相似元素；做商标/专利检索；兼容性表述用 `compatible with`，不写 `for [brand]` 作为主卖点。

### 5. 平台受限词与类目

- 武器/刀具、药品、成人、种子、激光、无线电、电池运输
- `Amazon's Choice`、`Best Seller` 等平台标识
- 促销/紧迫感：`limited time`、`only 3 left`（不真实）
- 评价/评分相关：`5-star`、`review us`

处理：按站点政策和类目要求处理；不确定就开 case 问。

### 6. 图片与标签

- 主图纯白底、产品占比、无文字/水印/边框（按类目）
- 副图不能有虚假对比、错误尺寸
- 包装需含：原产国、警告语、成分/材质、批次
- 加州 Prop 65 警告（如适用）

## 输出格式

````markdown
## 结论
高风险 x 项 / 中风险 x 项 / 低风险 x 项。建议上线前必须处理：...

## 风险清单
| # | 原文/位置 | 风险类型 | 等级 | 为什么危险 | 建议改法 | 需要什么证明 |
|---|---|---|---|---|---|---|

## 改写后的文案
...

## 上线前检查清单
- [ ] 去掉绝对化词
- [ ] 认证与型号一致
- [ ] 图片无竞品元素/水印
- [ ] 包装标签齐全
- [ ] 后台词无品牌词
- [ ] ...

## 需要准备的资料
- ...

## 免责声明
本检查基于公开平台规则的一般性理解，不构成法律意见；最终以亚马逊政策和当地法规为准。
````

要文件时写成 `reports/<产品>-compliance.md`。

## 红线

1. 不编造法规条款、认证编号、检测结论。
2. 不保证“这样写一定合规”。
3. 不建议规避审查、换词绕过、伪造文件。
4. 涉及专利/商标/医疗/儿童产品，明确建议专业检索或咨询。
5. 发现安全隐患（过热、漏电、窒息风险）时，优先建议停售排查，而不是改文案。
